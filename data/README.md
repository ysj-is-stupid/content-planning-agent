# 合成数据与规则清单

本目录用于评审时直接查看项目使用的合成资料和费用/耗时规则，不含真实用户数据、版权素材、密钥或供应商账单。

- `synthetic-materials-r1.json`：主题别名、合成素材、支持形式和许可边界。
- `pricing-and-fees.json`：r1/r2 制作报价、耗时、工具收费及预算计算口径。

当前运行时权威实现位于 `src/content_agent/catalog.py` 与 `src/content_agent/rules.py`；这里的 JSON 是便于审阅的同步清单，不由模型修改。修改目录、定价或收费策略时，必须同时修改代码、数据清单和对应测试，并提升版本号，避免旧任务被静默重算。
